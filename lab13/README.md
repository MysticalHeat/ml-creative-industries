# ЛР13. Альфа-демонстратор

Технический показ на синтетических примерах: `python3 -B lab13/walkthrough.py`. Используется код выпуска `A13-alpha-2.0`. Попробовать без сети можно с Python 3.10+. Для проверки: `python3 -B -m unittest discover -s lab13 -v`. Реальные заявки в демонстратор вводить не следует.

## Приложения

- [Запись показа (75 с)](Дополнение/показ.mp4)
- [Полная расшифровка](Дополнение/расшифровка.txt)
- [Хеши публичного комплекта](SHA256SUMS)

Для ручного прохода: `python3 demo.py --help` из `lab13`. `SHA256SUMS` в этом каталоге описывает именно открытый комплект; это отдельная ведомость, а не исходная ведомость учебного архива.
