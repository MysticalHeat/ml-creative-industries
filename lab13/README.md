# ЛР13. Альфа-демонстратор

Технический показ на синтетических примерах: `python3 -B lab13/walkthrough.py`. Используется код выпуска `A13-alpha-2.0`. Попробовать без сети можно с Python 3.10+. Для проверки: `python3 -B -m unittest discover -s lab13 -v`. Реальные заявки в демонстратор вводить не следует.
