# ЛР9. Контролируемый эксперимент

[Код](experiment.py) сравнивает пороговую модель по кварталу с константой. Условие успеха: BA ≥ 0,51 и recall класса 1 > 0. На одном квартале validation обе модели дали BA=0,50. Экспериментальная модель не принята. Полный повтор требует разрешённого набора и прогнозов; тесты можно запустить без них.
