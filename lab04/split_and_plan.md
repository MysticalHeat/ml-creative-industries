# Действующий split и возможный отдельный протокол

Split v1 не изменён: train — 2024Q3–2025Q2, 6 304; validation — 2025Q4, 1 059; test — 2026Q2–2026Q3, 1 910. Границы по датам подачи 01.10.2025 и 01.04.2026 с 92-дневными буферами перед ними. Для test отсечка — максимальная дата подачи, не подтверждённая дата экспорта. По CSV можно проверить непересечение кварталов, но не точные даты и окна. Это результаты проверки выпуска ЛР6.

Метка 1: реализация зарегистрирована от даты подачи по 90-й календарный день включительно; 0: при полном окне реализация за этот срок не зарегистрирована. Буферные, незрелые, дублирующие номера и спорные статусы исключаются по правилам подготовки.

Предложение, не текущая реализация: при разрешённом доступе установить надёжный ключ/ключи каждого автора, согласовать правила соавторства и закрепления авторских групп, включая группы через границы времени; документировать исключения, потери и изменения распределений. Сначала определить приоритет временной оценки и разрешения конфликтов, затем отдельно согласовать новый выпуск и повторить ЛР5, 7–9. До этого не заявлять независимость по авторам.

План Б: при отсутствии разрешённого доступа создать полностью синтетические данные без копирования записей, документировать генерацию и пересчитать метрики; выводы о предприятии по ним невозможны.
