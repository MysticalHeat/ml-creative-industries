# Пустые формы наблюдений

Для каждого фактически согласившегося участника использовать одну форму. До проведения все поля пусты; коды U1–U5 — заготовки, не свидетельство набора. Не хранить имена, контакты, реальные заявки, персональные и производственные данные.

| Версия, хеши, среда, сверка; код учебного случая | |
| Начало / завершение, время, результат, технический сбой | |
| Наблюдаемые действия, вопросы, ошибки, вмешательство и его время | |
