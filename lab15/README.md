# ЛР15. Пользовательская проверка

Протокол предполагает 3–5 участников целевой роли или заранее согласованную замену. Каждый проходит сценарий на синтетическом примере: объясняет прогноз, выбирает действие и проверяет сохранённое решение. [Пустые формы наблюдений](forms.md). Пользовательские сессии ещё не проводились.
