# Сводка и backlog — форма для заполнения

**Исследование не проведено; результатов и приоритетов по наблюдениям пока нет.**

После исследования указать версию, критерий, роли и ограничения выборки; участников приглашено / допущено к анализу / начато / успешно без помощи / с помощью / прервано; долю или «не рассчитана» и причины исключений без персональных сведений.

| Тема и ссылки на номера наблюдений | Число участников с проблемой / начавших | Наблюдение отдельно от интерпретации | Возможный ущерб | Приоритет и основание | Изменение и ожидаемый эффект | Как проверить после изменения |
|---|---|---|---|---|---|---|
| | | | | | | |

Предлагаемая шкала: P1 — риск неверного решения/раскрытия либо невозможность завершить сценарий; P2 — прочие повторяющиеся затруднения; P3 — локальные улучшения. Учитывать частоту **и** ущерб, не ранжировать исключительно по простоте исправления. Редкое критическое событие также может быть P1.

Решение по [карточке и рискам](../lab14/РЕЕСТР_РИСКОВ.md): не заполнено. Для нового риска указать связь с наблюдением; если новых рисков нет — явно обосновать после анализа. Нельзя считать пустую таблицу отрицательным результатом.
