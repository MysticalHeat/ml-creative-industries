# ЛР6. Разметка и подготовка данных: кайдзен-предложения

Елманов Илья, МИК21. Задача — по истории заявки определить, зарегистрировали ли её реализацию в первые 90 календарных дней от подачи.

## Материалы для проверки

1. [Инструкция разметчика v1](annotation_guideline.md) и [пограничные случаи](edge_cases.md).
2. **Версия набора:** `kaizen_v1.csv`, 9 273 записи, поля `quarter`, `effect_declared`, `implemented_90d`, `split`. SHA-256: `82cd0538aa2b0fa5b8d84cef3e52c8777e6e12f9be71426e91208477cbd71220`. Сам файл передан в основном ZIP в [ответе ДО.СКИФ](https://do.skif.donstu.ru/mod/assign/view.php?id=107216); в GitHub размещены описание, код и агрегаты.
3. **Статистика:** метка `1` означает регистрацию реализации со дня подачи до 90-го дня включительно. Метка `0` ставится только при полном окне наблюдения. Спорные случаи исключаются. [Сводка отбора](preparation_audit.json).

   | Выборка | Метка 0 | Метка 1 | Всего |
   |---|---:|---:|---:|
   | Обучающая | 3 254 | 3 050 | 6 304 |
   | Валидационная | 547 | 512 | 1 059 |
   | Тестовая | 869 | 1 041 | 1 910 |
   | **Всего** | **4 670** | **4 603** | **9 273** |

4. **Контроль разметки:** один человек проверил 24 карточки обучающей выборки, не видя ранее сохранённых меток. Ответы совпали с исходным пилотом ИИ, сверенным с кодом: **24/24**, из них 13 единиц и 11 нулей. Для случая 03 потребовалось пояснить, что «регистрация реализации» относится к полю «Реализовано». Бланк и исходные ответы переданы в дополнении через ДО.СКИФ. Это проверка применения инструкции на пилоте, а не проверка достоверности первичного реестра. [Код отбора и сверки пилота](pilot.py).
5. [Код предобработки](prepare.py) и [тесты граничных условий](test_prepare.py).

## Как проверить

Из корня репозитория, Python 3.10 или новее, без дополнительных пакетов:

```sh
python3 -B -m unittest discover -s lab06 -p 'test_*.py' -v
```

Для полного повторения подготовки нужен исходный реестр в разрешённой локальной среде:

```sh
python3 lab06/prepare.py /путь/к/исходному.csv --output-dir /путь/к/закрытому/результату
```

Последняя дата подачи используется как отсечка, а не как подтверждённая дата выгрузки. Разбиение временное; независимость выборок по авторам не установлена. Столбец `effect_declared` указывает на заполненность поля эффекта; его доступность на момент подачи не подтверждена.
