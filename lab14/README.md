# ЛР14. Карточка модели и риски

**Модель:** константа 0, большинство на train. **Назначение:** демонстрация интерфейса. **Ограничения:** пропущены все 512 положительных заявок validation, прогноз не оценивает ценность предложения. Главные риски: применение класса 0 для автоматического отказа; совпадение авторских полей между частями; использование поля эффекта, доступность которого в момент подачи не установлена.
