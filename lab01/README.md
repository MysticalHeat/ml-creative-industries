# ЛР1. План проекта

Цель проекта — проверить, можно ли по сведениям на момент подачи заявки прогнозировать регистрацию её реализации в течение 90 дней. Основные этапы: определение метки, выпуск данных, базовая модель, эксперимент, экспертный сценарий и проверка понятности интерфейса.
