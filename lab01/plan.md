## Цель проекта и личная зона ответственности

Цель общего проекта — разработать систему, которая оценивает вероятность одобрения кайдзен-предложения (КП), прогнозирует срок его внедрения и формирует рекомендации по улучшению предложения перед подачей.

Моя роль в проекте — **участник 2, специалист по машинному обучению**. Я отвечаю за выбор алгоритмов, разработку и обучение моделей, оценку их качества и реализацию механизма рекомендаций.

Ниже представлен план моей личной работы в общем потоке спринтов проекта. Сроки отсчитываются от начала проекта; перечисленные результаты являются планируемыми.

## План личной работы по спринтам

### Спринт 1. Постановка задач машинного обучения

**Срок:** неделя 1.

**Мои задачи:**

- Определить целевую переменную классификации: решение по КП — одобрено или отклонено.
- Определить целевую переменную регрессии: количество дней от одобрения КП до завершения его внедрения.
- Выбрать метрики: ROC-AUC для классификации и MAE в днях для регрессии.
- Сформулировать требования к составу и качеству данных для обучения.

**Результат моей работы:** описание задач моделирования, целевых переменных, метрик и требований к набору данных.

### Спринт 2. Подготовка данных для моделирования

**Срок:** недели 2–4.

**Мои задачи:**

- Согласовать с участником, отвечающим за аналитику, состав признаков и формат передаваемого набора данных.
- Проверить пригодность подготовленного набора данных для обучения моделей.
- Определить схему разделения данных на обучающую, валидационную и тестовую выборки с учётом дат подачи КП.
- Разработать обработку текстовых и категориальных признаков в составе модельного пайплайна. Обучать преобразования только на обучающей выборке.
- Исключить утечку целевой переменной: не использовать при прогнозировании одобрения итоговый статус, причины отклонения, фактический эффект и даты последующих этапов.
- Для регрессии сформировать выборку предложений с завершённым внедрением и корректными датами.

**Результат моей работы:** пайплайн подготовки признаков и выборки для обучения и оценки моделей.

### Спринт 3. Анализ признаков и разработка базовых моделей

**Срок:** недели 5–6.

**Мои задачи:**

- Использовать результаты исследовательского анализа для выбора признаков моделей.
- Рассчитать качество простых ориентиров: постоянного прогноза вероятности одобрения и прогноза медианного срока внедрения по обучающим данным.
- Обучить логистическую регрессию для классификации и линейную регрессию для прогноза срока внедрения.
- Рассчитать исходные значения ROC-AUC и MAE на валидационных данных для дальнейшего сравнения.

**Результат моей работы:** базовые модели и таблица исходных значений метрик.

### Спринт 4. Разработка основных моделей и рекомендаций

**Срок:** недели 7–9.

**Мои задачи:**

- Сравнить логистическую регрессию, Random Forest и CatBoost для прогнозирования одобрения КП.
- Сравнить линейную регрессию, Random Forest Regressor и градиентный бустинг для прогнозирования срока внедрения.
- Подобрать гиперпараметры с помощью кросс-валидации на обучающих данных с учётом временной структуры выборки.
- Реализовать поиск похожих ранее реализованных КП по косинусной близости текстовых представлений.
- Разработать формирование рекомендаций по полноте описания проблемы, предлагаемого решения и обоснования ожидаемого эффекта.

**Результат моей работы:** обученные модели, результаты подбора гиперпараметров и прототип рекомендательного компонента.

### Спринт 5. Оценка качества и интерпретация

**Срок:** недели 10–11.

**Мои задачи:**

- Оценить выбранные модели на отложенной тестовой выборке, не использовавшейся для выбора алгоритмов и подбора гиперпараметров.
- Сравнить качество выбранных моделей с базовыми решениями по ROC-AUC и MAE.
- Проанализировать типичные ошибки прогнозирования и значимость признаков.
- Проверить рекомендации на примерах КП: оценить соответствие найденных аналогов и конкретность советов совместно с другим участником проекта.
- Описать ограничения моделей и возможные направления улучшения.

**Результат моей работы:** отчёт о качестве моделей, разбор ошибок и примеры работы рекомендаций.

### Спринт 6. Подготовка результатов к представлению

**Срок:** недели 12–14.

**Мои задачи:**

- Сохранить обученные модели и используемые преобразования признаков.
- Оформить код обучения и прогнозирования, зафиксировать зависимости и параметры экспериментов.
- Подготовить техническую часть README с инструкциями по запуску и описанием входных и выходных данных.
- Подготовить свой раздел отчёта и слайды о моделях, рекомендациях и результатах оценки качества.

**Результат моей работы:** воспроизводимый код, сохранённые модели, техническая документация и моя часть презентации.
