# ЛР12. Предметные правила и решение эксперта

Когда сведений недостаточно или модель недоступна, заявка направляется на ручную проверку. При достаточных сведениях оператор может подтвердить или исправить результат. [JSON](../lab13/rules.json) описывает правило, а [Python-модуль](../lab13/demo.py) исполняет его; эскалация в демонстраторе — локальная запись.
